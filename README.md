## Deutsch

Zufalls-Klingelton macht aus deiner persönlichen Musiksammlung einen dynamischen Klingelton-Pool. Du wählst deine Songs aus, aktivierst die Funktion und lässt die App automatisch einen Titel als Systemklingelton verwenden.

### ✨ Was kann die App?

- Songs aus der Audiobibliothek oder aus Dateien auswählen
- Mehrere Tracks gleichzeitig zum Pool hinzufügen
- Titel, Interpret und Dauer übersichtlich verwalten
- Tracks direkt in der Liste vorhören
- Einzelne Tracks löschen oder den gesamten Pool leeren
- Aktiven Klingelton in der Liste sichtbar markieren
- Zufällige Auswahl ohne direkte Wiederholung
- Klingelton täglich oder nach jedem beendeten eingehenden Anruf wechseln
- Vorherigen Systemklingelton beim Deaktivieren wiederherstellen
- Nicht mehr erreichbare Dateien automatisch aus dem Pool entfernen
- Pool und Einstellungen dauerhaft speichern

### 🚀 So funktioniert es

1. Beim ersten Start die benötigten Android-Zugriffe einrichten.
2. Über **Hinzufügen** Songs aus der Audiobibliothek oder dem Gerätespeicher auswählen.
3. Die Zufalls-Klingelton-Funktion aktivieren.
4. Den Wechselmodus auswählen: **täglich** oder **nach jedem Anruf**.

Die App verwendet ausschließlich die von dir ausgewählten Tracks. Wenn die Funktion deaktiviert ist, bleibt der normale Systemklingelton aktiv.

## English

Zufalls-Klingelton turns your personal music collection into a dynamic ringtone pool. Pick your songs, enable the feature and let the app use a track from your pool as the system ringtone.

### ✨ Features

- Select songs from the audio library or local files
- Add multiple tracks at once
- Manage title, artist and duration in one place
- Preview tracks directly from the list
- Remove individual tracks or clear the entire pool
- Clearly highlight the currently active ringtone
- Random selection without immediate repetition
- Change the ringtone daily or after every completed incoming call
- Restore the previous system ringtone when disabled
- Automatically remove files that are no longer reachable
- Persist the track pool and settings across restarts

### 🚀 How it works

1. Grant the required Android access during the initial setup.
2. Use **Add** to select songs from the audio library or device storage.
3. Enable the random ringtone feature.
4. Choose a switching mode: **daily** or **after every call**.

The app only uses tracks selected by you. When the feature is disabled, Android’s regular system ringtone is used.
